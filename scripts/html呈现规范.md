# HTML 呈现规范（狗不扯蛋专题研究 · HTML 版）

本文件规定 Step 7 / Step 8 产出的两个产物长什么样：交互式 HTML 报告，以及与它同源的 md 底稿。网页按 `网页模板.html` 的代码结构写，配色与交互已经写进模板的样式和脚本里；md 表格由 `填入表格.py` 生成。本文件用于人工复核与后续改版。

## 一、交付形态

1. 单个 `.html` 文件，无外链 CSS/JS/字体/图片，双击即可打开，断网可用。
2. 图表由内联 SVG 重绘，不引用 md 里的位图（PNG 仅供 md/PDF 版使用）。
3. 桌面优先，1280px 为设计宽度；390px 窄屏不得出现横向溢出。
4. **配套的 md 底稿**：纯 Markdown，正文段落 + `**表N.标题**` 表格 + 资料来源行；没有图片、没有 mermaid、没有图表请求。表N 与 HTML 的 图N 是同一处数据的两种形态，编号一致。
5. **一处数据两个出口**：两张产物都从 `charts.json` 生成，不许在 md 里手写第二遍数字。先跑 `填入表格.py` 回填 md，再跑 `图表SVG.py` 出图、`贴图.py` 按段号贴进网页。

## 二、页面骨架（自上而下）


| 区块  | 规则                                                  |
| --- | --------------------------------------------------- |
| 刊头  | 墨蓝底、白字、只有报告标题，**不加** kicker、日期、副标题、方案切换             |
| 摘要  | 原报告摘要原文逐段照录，不改写、不删减；框内左上角一个「摘要」小标；左侧 3px 墨蓝竖线、浅灰底   |
| 主枝  | Ⅰ–Ⅳ 四条，罗马数字编号（与章号 01–10 解耦）；每枝只写枝名，**不写**枝下的副标题或说明句 |
| 章卡区 | 单列大纲，左侧一条竖导线，章卡挂在导线上                                |
| 页脚  | 一行合规声明（见第六节）                                        |


## 三、章卡

**收起态**（默认全收起）：

```
01  这轮减仓，有多少是跌出来的？                    ＋
    ▪ 论据一（完整陈述句，带数字）
    ▪ 论据二
    ▪ 论据三…
```

1. 标题必须是**短问句**，≤16 字，直接问该章要回答的问题；不设副标题，不并列原名。
2. 标题下给 **3 条**核心论据，每条是一个完整陈述句（含关键数字），不是关键词。
3. 第 3 条之后若还有论据，接一个灰色省略号「…」，不另起一行。
4. 右侧只有＋/－，**不放缩略图**（缩略图会破坏列表的整洁）。

**展开态**：只保留章标题（问句）→ 2–4 张图表 → 正文段落。不重复论据列表，不出现「本章要点」这类小标题。

## 四、图表

1. 每章 **2–4 张**，全文按阅读顺序连续编号「图1、图2……」；md 里同一处数据写成「表N」表格，数据全部在 `charts.json`。
2. 首图紧跟章标题；其余按 `after`（第几段之后）插入论证推进处，不堆在章末。表的位置靠 `anchor`（表前一段开头 16 字）锁定，段落被重写后锚句失效会回退到段号，回填时要看脚本打印的锚句对不对得上。
3. 图题是陈述句，概括图里的事实；单位写进 `unit`；资料来源只写机构/数据库与日期。
4. 每张图右上角只保留「数据」按钮，点开在图形下方展开数据表（表头、数值、单位、来源），**不提供复制**。
5. 支持图型：`group`（分组柱）、`bars`（单序列柱）、`lolli`（分位棒）、`share`（占比条）、`hbar`（方向条）、`compare`（对比条）、`pe`（PE 双序列）、`diverging`（上修/下修背离）、`marker`（单值＋参考线）。
6. 数据必须来自正文或已核验来源；由加减得到的余额（如占比的「其他」项）要在 `src` 注明「结构余额」。

## 七、交互与可访问性

1. 每张章卡是 `<button aria-expanded aria-controls>`，点击展开/收起，`aria-expanded` 同步。
2. 键盘可操作：Tab 聚焦有青色焦点框，Enter/Space 触发。
3. 不提供「全部展开／全部收起」，避免整页变成一堵墙。
4. 装饰性 SVG 一律 `aria-hidden="true"`，图表 SVG 带 `role="img"` 与图题文字。

## 八、交付前校验

```
python3 <research-html>/scripts/validate_html.py "[报告标题].html" --scope full --browser always
```

要求：`status=pass`、`findings` 为空、1280 与 390 均无横向溢出、无 JS 报错、「数据」表开合正常。

## 九、禁止事项

- 禁止 mermaid、外部图片、外链资源；
- 禁止在 md 里手写表格数字、残留图题或「图表请求」行；
- 禁止复制按钮、缩略图、方案切换器、「结构/适用/取舍」说明条；
- 禁止在刊头堆副标题，禁止章卡设副标题；
- 禁止把图表数据写死在脚本里——数据只能来自 `charts.json`。
