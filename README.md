# 狗不扯蛋专题研究
狗不扯蛋专题研究是一个搭载在金融投资研究AI平台上的SKILL，这个SKILL的逻辑框架是：把不同维度不同洞察的研究框架，写成可拼装的研究模板，来研究方方面面的专题。

## 先说方法论

我们认为好的报告的前提是好的问题。比如你想问存储有没有机会，实际上你想问的可能是存储的供需格局如何，或者更进一步，存储的供应瓶颈为什么存在，需求的增长是否为周期性增长，有没有价格弹性，如果出现反转信号会是什么样子的等等。

我们把问题按照以下几个维度做了一些归类：
- 产业链景气度梳理相关
- 供需矛盾相关
- 估值方法和盈利预测相关
- 国内政策相关
- 海外政治相关
- 宏观变化相关
- 技术变革相关
- 商业模式相关
- 市场风格相关

并且，我们给以下特定专题适配了标准的提问框架：
- 当日复盘
- 个股研究
- 行业研究
- 技术路径验证

本skill的工作逻辑是，把适配于该话题的相关问题拼成一篇报告的骨架，然后撰写成一篇报告。

## 再说说怎么用

如果你想研究黄金当下的定价受美元的哪些因素影响，你可以这么跟paiwork说：“用[狗不扯蛋专题研究]帮我研究以下话题：黄金当下的定价受美元的哪些因素影响”

或者如果你已经有自己的立场和观点了，也可以试试这么跟paiwork说：“用[狗不扯蛋专题研究]帮我完善以下观点：黄金当下的定价受美元信用影响而非美元的利率环境，我需要系统性地论述”

当然你也可以反着用：“用[狗不扯蛋专题研究]挑战我的观点：黄金当下的定价受美元信用影响而非美元的利率环境”

另外，我不确定它有没有能力研究个股，但我确实没有专门围绕个股研究这件事做过开发。你要是好奇可以试试看呢？

以及，我特别建议的是，当你看了一篇报告之后，顺着再往下问一些细节相关的问题，它的效果可能出奇得好。
